# Security Policy

## Supported versions

The current `main` branch is maintained on a best-effort basis. Starter templates are **examples**, not a security certification.

## Reporting

Please report vulnerabilities privately using GitHub's **Report a vulnerability** feature (Security → Advisories) when enabled for the repository. Do not put live credentials or exploit details in public issues. If private reporting is unavailable, ask maintainers for a secure reporting channel without posting sensitive details.

## Scope

Security reports may concern code injection, input-validation bypass, leaks of sensitive files, or unsafe template defaults. Reproducible, minimal test cases are appreciated.
